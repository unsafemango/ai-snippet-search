# AI-Powered Code Snippet Search Engine
A java application that allows users to search the web for code snippets and solutions using [SerpApi](https://serpapi.com/)

## Project Description
Instead of relying on a static list of code snippets, this app performs real-time web searches to fetch relevant programming examples and tutorials.
It's useful for quickly finding updated code patterns, solutions, and explanations.

## Api Routes
| Month | Endpoint                    | Description                                                        |
|-------|-----------------------------|--------------------------------------------------------------------|
| GET   | /search?query={searchQuery} | Searches the web for programming snippets related to {searchQuery} |

## Environment Variables

*SERP_API_KEY* = your_api_key_here

*OPEN_API_KEY* = your_api_key_here
